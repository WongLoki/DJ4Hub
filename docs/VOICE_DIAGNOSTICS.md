# 拨号失败诊断

拨号或接听命令失败后，后端依次读取 `AT+CEER`、`AT+QCFG="ims"`、`AT+QCFG="usbcfg"`。每项查询超时为 2 秒；只读取，不写配置、不重启、不重拨。失败原因是一次尽力采样，后台 AT 查询或固件行为可能影响 CEER，不能视为精确网络侧信令记录。

服务日志搜索 `call_action_failed`，包含动作、耗时、协议结果、错误及诊断快照。快照只保留白名单协议行，排除电话号码回显、CLCC 和短信通知；查询失败记为 `query_failed`，不推断功能已关闭。客户端仍收到原始失败说明，附带同一快照。

`ims=0,0` 的第一个 0 是沿用 MBN 默认设置，不是强制关闭；配置读取不代表 IMS 注册状态。USB 语音位为 0 是调查线索，不作为本版本阻止拨号的依据。音频待机也不证明运营商通话可用。

本版本没有自动开启 IMS/UAC。音频初始化支持原始 RMNET/ECM 组合及其末尾带单个 audio 的组合，不重复追加 audio，停止时恢复进入会话前的 USB functions 并关闭音频流。

2026-09-13 单变量实验：在确认无语音通话、保存本机私有配置备份后，仅将 DJI 设备 usbcfg 末位 UAC 从 0 改为 1，严格回读后执行 CFUN 重启。重启后读取到 diag,serial,ecm,ffs,audio，root 为 0、内核 3.18.44；IMS 仍为 0,0，usbnet 仍为 1，CGDCONT 与备份一致。该配置已保留在本次测试设备上；不是刷固件，也没有加入所有新设备的自动写入流程。实际运营商呼叫仍需测试，不能以 USB 接口枚举成功替代。
