# DJI 第一代 4G 模块：初始化与音频方案

核验日期：2026-09-13。方案为**保留原厂固件、一次 ADB 初始化、运行时音频加载**，不是定制刷机包。

## 实际问题与结论

本次新设备报告 QDC507GLEFM21，编译时间 Jan 29 2024 18:15:19。
原 USB 配置为 `0x2CA3,0x4006,1,1,1,1,1,0,0`，ECM 网络接口已存在，但 ADB 位为 0。
原软件只处理 ADB 已连接后的 root，不能完成新设备的首次授权。

受控测试完成：

- 通过 AT+GSN 获取稳定身份，备份原配置；不将实际 IMEI、SIM 信息或挑战写入仓库。
- 旧式 QADBKEY 挑战可读取；对应授权和仅开启 ADB 的配置被设备接受。
- 重启后核对同一 IMEI，USB 配置为 `0x2CA3,0x4006,1,1,1,1,1,1,0`。
- root shell 返回 uid=0；内核为 3.18.44，USB functions 为 diag,serial,ecm,ffs。
- 固定哈希音频运行文件成功加载，服务 prepare 返回 active=true；ALSA 声卡及 USB audio 出现。
- 诊断时启动的 5037 ADB 服务曾占用接口；停止该诊断服务并重新启动专用 5039 服务后恢复。
- 未刷固件、写入 boot/MTD/NV、修改 IMEI、拨打电话、录音或开启 Mac 麦克风。

这验证了本设备的授权、root 与音频待机，不代表新设备双向通话、长期待机、所有硬件批次或上网并行均已验收。

### 后续拨号验证（同日）

同一张 SIM 在旧设备能通话，新设备拨号返回 ERROR。旧设备初始化前备份中的 IMS 为 1,1，新设备为 0,0。先单独开启 UAC 并重启，拨号仍失败；随后另行备份，仅设置 `AT+QCFG="ims",1` 并重启，回读变为 1,1，用户确认通话恢复。USB、ECM、APN 与该次 IMS 修改前备份一致。此结果支持 IMS 配置是本次故障关键因素，但未单独撤销 UAC 做反向实验，也未进行长期稳定性验证。

上述 UAC/IMS 写入是用户授权后的设备实验，不是当前软件的自动配置步骤。软件现已兼容末尾带单个 audio 的 RMNET/ECM 组合，并在拨号/接听失败后提供只读诊断。详见 [拨号失败诊断](VOICE_DIAGNOSTICS.md)。

## 产品流程

1. 确认仅一台 DJI USB 模块，锁定 USB 位置；检查无语音通话或未知 CLCC 状态。
2. 使用 AT+GSN 校验 IMEI，严格校验 QDC507 固件和完整 USB 配置。
3. ADB 未开启时，先将配置写入本机私有备份并同步到磁盘。
4. 仅接受已验证的旧式 8 位挑战，使用独立 Go 实现的协议派生，不依赖 Python、OpenSSL 或联网。
5. 授权后再次核对身份和原配置，只将 ADB 位从 0 改成 1；不更改 UAC、网络模式、IMS/APN 或 VID/PID。
6. 无通话时重启，核对原身份、配置与 USB 位置。超时不会无限重启。
7. 必要时重新提交当前旧式挑战。ADB 仍不可连接则明确提示接口占用，不自动杀其他程序。
8. 检查 root（需要时标准 adb root）、内核及 USB functions，校验驱动哈希后加载临时音频运行时。
9. 挂断关闭电脑音频，保留模块待机。退出或心跳失效恢复临时 USB 音频配置，不执行 unroot。

已经启用 ADB 且可连接的设备不会重复写配置或重启。USB 位置变化、多设备、身份不符、未知挑战、备份失败、呼叫状态异常均停止。

## 客户端与 Web

新客户端的音频准备请求携带 `X-DJ4Hub-Initialize: 1`，可完成首次初始化。旧客户端不携带此字段，仍只使用已经授权的 ADB。
Web 将首次授权说明升级到版本 2，说明 ADB 授权保留、可能重启及不刷机；旧的临时驱动授权不能直接替代新授权。
原有本机同源和自定义请求头检查不变。初始化与拨号共享 audioMu，不能同时由本服务发起。
外部程序仍可能竞争设备，因此不能替代硬件独占管理；请勿同时运行多个模块管理工具。

## 保存与持久化边界

配置备份：`~/Library/Application Support/DJ4Hub/device-backups/`，目录 0700、文件 0600。
内容含设备 IMEI、固件信息、原 USB 功能位及时间，不含授权密码。
此目录不会自动加入通信记录的云盘备份。

ADB 接口配置保存在设备；授权不自动撤销。不承诺所有固件重启后都保持 root，因此每次仍检查权限。
音频驱动仍位于设备 `/tmp`，重启后重载。没有设备端持久启动服务，也没有宣称完整固件备份或一键刷机恢复。
配置备份不是 raw NAND/OOB/ECC、NV/EFS/QCN 备份，不能用来救砖。

- 新版 `/Applications/DJ 4G Hub.app` 启动后，服务回读 active=true；电话页实测显示「模块待机就绪 · 电脑麦克风未开启」。初次关闭 ADB 的设备授权路径由受控实验验证；Go 自动初始化完整路径通过模拟测试，已启用设备上的自动待机通过本机客户端实测。

完整定制固件需要另行取得匹配的原厂底包、分区布局、刷写程序、安全链信息、各台设备独有数据备份，并在备用硬件完成恢复演练。标准 EG25/EC25 固件不能直接跨刷。
