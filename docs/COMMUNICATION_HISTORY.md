# 通信记录与可选音频

音频 USB 配置白名单支持 `diag,serial,rmnet,ffs` 和 `diag,serial,ecm,ffs`。初始化仅在当前组合后临时追加 `audio`，停止时恢复本次会话开始时读取的原组合；不为启用音频切换 ECM／RMNET。两种配置的校验与恢复逻辑已有回归测试，ECM 下的真实音频和网络并行仍需设备验收。

macOS 客户端默认在检测到设备后延迟 2 秒后台准备模块音频，只加载驱动并续期待机，不申请麦克风权限、不启动电脑音频流。拨号／接听时连接麦克风与扬声器；准备尚未完成时会等待。电话页可关闭“启动后后台准备”。有通话时延后准备；每次检测到设备连接后失败只自动尝试一次，手动拨号仍可重试，检测到拔插后允许再次准备。退出时取消准备并恢复 USB；初始化会使 USB 短暂重连。

音频初始化会先验证已支持的固件、内核、USB 标识和启动 ID，再检查 ADB UID。非 root 时仅尝试标准 `adb root`，等待同一 USB 位置、同一次设备启动重新连接并确认 UID 0 后才上传驱动；不自动开放 ADB、不绕过授权、不解锁或刷写固件。固件禁止 root 或尚未授权时停止并提示。

macOS 客户端在任何页面都轮询来电／短信事件，通过系统通知播放一次提示音，可在设置关闭。首次启动请求通知权限；系统静音、专注模式或禁用通知声音会影响播放。Web 需先点击“开启来电／短信提示音”，保持页面运行；浏览器后台节流会延迟提示，多客户端同时开启可能各自提示。既有短信不重放提示；旧时间戳短信（早于本次服务启动 30 秒）不触发提示。提示不包含号码或短信正文，不保存录音。

客户端短信页的「按卡记录」、电话页的「最近通话」，以及 Web 对应入口，共享本机历史存储。可查看当前卡、全部卡片、指定 ICCID 尾号或未归属记录，每页 100 条，可继续加载。原生历史视图打开时读取，可手动刷新；换卡不会删除旧记录。号码仅作为记录字段，不作为卡片身份。

历史保存在 macOS `~/Library/Application Support/DJ4Hub/communication-history.sqlite`（SQLite，权限 0600，**未加密**），目录权限 0700。无需安装数据库服务。仅允许一个后端进程持有历史存储，客户端与 Web 复用同一服务；兼容旧 JSON 服务的互斥锁，避免两个版本同时写入。

新版服务首次启动会在事务中导入同目录的 `communication-history.json`，导入记录和完成标记一起提交。原 JSON 原样保留作迁移前备份，后续启动不会重复导入或覆盖数据库的新记录；无旧文件则直接创建数据库。JSON 损坏或存在冲突 ID 时停止启动并回滚导入，不覆盖原文件。SQLite 开启 WAL 和 FULL 同步，按 ICCID / 类型建立索引并在数据库中分页。备份运行中的数据库应使用 SQLite 在线备份工具，不能只复制主文件而遗漏 WAL；也可先停止服务再复制。旧 JSON 不包含迁移后的新增记录，不能用它直接回退最新数据。请勿将历史文件上传仓库或用作公开演示素材。

归属采用操作前后均成功读取且一致的 ICCID；eSIM 按 Profile 的 ICCID 区分。SIM 存储（SM）读取的短信可归属当前卡；模块存储（ME）及串口回调无法证明原始卡片身份，保守放入「未归属」。旧收件箱仍是模块读取缓存，按卡历史为独立入口。发送记录的“已提交模块”不代表对方送达，失败可能包含部分分段已发送。归档失败时自动清理模块短信会停止。

通话记录来自软件运行期间的 CLCC 观测（约 3 秒一次及拨号/挂断时查询），不是运营商账单，极短来电可能漏记，时长为估算值。查询中断或重启会标记“记录中断”，不会捏造结束时间；不能补回此前在其他手机上的历史。模拟模式不写真实历史文件。


## 云盘备份

主数据库保持本地。客户端设置支持自选备份目录、自动快照和合并恢复，具体步骤见[原生客户端说明](../apps/hub-macos/README.md#通信记录云盘备份)。自动备份使用 VACUUM INTO 生成包含已提交 WAL 内容的完整快照，而非复制正在写入的主文件。备份未额外加密，只能放在自己的私密目录；云盘同步成功需自行确认。

## ICCID 填充兼容

部分模块将 BCD 填充字符 F 一并返回。归档读取会去掉单个末尾 F/f 后验证数字卡号；中间夹杂字符、多个填充或长度不合规则拒绝归属。仍要求操作前后的 ICCID 一致，不会通过 IMEI、设备序列号或电话号码猜测卡片身份。此前未归属记录保持原状，可在“全部 SIM 卡／未归属”查看。
